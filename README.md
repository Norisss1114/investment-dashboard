## 🆕 v14.4 のアップデート（APIキー：st.secrets対応）
Streamlit Cloud で動かせるよう、APIキー取得を **st.secrets → 環境変数 → 空** の優先順位に統一しました。
- 対象キー：`FINNHUB_API_KEY` / `OPENAI_API_KEY` / `ANTHROPIC_API_KEY` / `DISCORD_WEBHOOK_URL`（Telegramも同様）。
- 共通取得関数 `config.get_secret()` を新設し、**API状態表示と実際の挙動が常に一致**するよう全箇所を統一。
- **OpenAIが未設定でもAnthropicが設定済みなら「フル機能稼働: Finnhub + Anthropic」**と表示。OpenAI未設定を強く警告しません（情報メッセージに緩和）。

### Streamlit Cloud での設定
1. アプリの **Settings → Secrets** に以下を貼り付け（`.streamlit/secrets.toml.example` を参照）:
```
FINNHUB_API_KEY = "..."
ANTHROPIC_API_KEY = "..."   # OpenAIでも可（どちらか一方でフル機能）
DISCORD_WEBHOOK_URL = "..." # 通知を使う場合
```
2. 保存して再起動すると、サイドバーのAPI状態が「✅」になります。

### ローカルでの設定
- `.env` か環境変数に同名キーを設定（従来どおり）。または `.streamlit/secrets.toml` を作成。
- 取得優先順位は **st.secrets → 環境変数 → 空**。未設定でも代替モードで動作します。

## 🆕 v14.2 のアップデート（保有銘柄とウォッチリストを完全分離）
「持っている株」と「これから買いたい株」を混ぜない設計にしました。
- **デフォルトウォッチを自動登録しない**：初回起動時のウォッチリストは**空**（NVDA等は自動保存されません）。
- **おすすめ監視銘柄**：AI/半導体(NVDA,AMD,AVGO,MRVL)・AIソフト(PLTR)・電力/AIインフラ(VST,GEV,CEG)・エネルギー/原子力(XOM,CCJ)を**提案としてカード表示**。各カードの「＋追加」を押したものだけウォッチに保存。
- **サイドバー表示を3分割**：💼保有銘柄 / ⭐ウォッチリスト / 💡おすすめ監視銘柄。
- **Moomoo同期**：読み取った銘柄は `positions.json` に保存（既定でウォッチには入れない）。「保有銘柄をウォッチリストにも追加する」チェックをONにした時だけ `settings.json` にも追加。
- **今日のアクション**：Ⓐ保有銘柄へのアクション（売る/継続/利確/損切り/逆指値更新）と Ⓑウォッチ銘柄へのアクション（買う/待つ/見送り）を分けて表示。
- **ホーム**：💼保有中 / ⭐買い候補（ウォッチ）/ 🛒買い候補（発掘TOP3）/ 💡おすすめ監視銘柄（未登録時）を分離表示。
- **空状態**：保有もウォッチも無い時は「まずはMoomoo同期で保有銘柄を登録するか、銘柄検索でウォッチリストに追加してください」＋おすすめカードを表示。
- **発掘**：候補は「☆ウォッチ追加」でウォッチに入るだけ（勝手に保有にしない）。

### 用語と流れ
- **保有銘柄**：実際に持っている株。`📷 Moomoo同期`で取り込み、`user_data/positions.json` に保存。
- **ウォッチリスト**：これから買うかもしれない買い候補。検索/発掘/おすすめから自分で追加し、`user_data/settings.json` に保存。
- **おすすめ監視銘柄**：初回用の提案。自動登録はされません（押した時だけウォッチに入る）。
- **Moomoo同期後の流れ**：スクショ読取→差分プレビュー→「💾 同期して保存」で保有に反映。必要なら「ウォッチにも追加」をON。
- **今日のアクションの見方**：Ⓐ＝保有株に対する売買/逆指値の指示、Ⓑ＝ウォッチ株を買うか待つかの判断。

## 🆕 v11 のアップデート（🧠 ニュース精密解析）
ニュースを“要約”で終わらせず、**保有株・これから買う株への影響**を短期/中期/長期でシナリオ分析します。
- **新ページ「🧠 ニュース精密解析」**を追加。対象は 保有銘柄 / ウォッチリスト / 銘柄発掘TOP20 / 今日のアクション（保有＋ウォッチ）。
- **時間軸**：直近24時間 / 7日 / 30日でニュースを抽出。影響は「今日〜3日 / 1〜2週間 / 1〜3ヶ月」で評価。
- **ニュース細分類**：決算 / ガイダンス / アナリスト評価 / 製品・サービス / 規制 / 訴訟 / 金利 / 原油 / 地政学 / 競合 / 業界全体 / 個別材料。
- **株価影響**：各ニュースに 影響度(-5〜+5) / 信頼度(高中低) / 織り込み判定 / 短期・中期の効き方 / 下落リスク / 上昇余地。
- **織り込み判定**：直近の株価変化・ギャップ・出来高・戻りから「未織り込み／一部／ほぼ織り込み済み」を推定。
- **シナリオ予測**：銘柄ごとに **強気 / 中立 / 弱気** の想定株価レンジ＋確率の目安（テクニカルとニュース傾向で配分）。
- **マクロ連動**：銘柄のテーマに応じて CPI / FOMC / 金利 / 原油 / ドル指数 / 地政学 / VIX の効き方を表示。
- **判断**：保有→継続/一部利確/全利確/損切り/買い増し禁止/ニュース待ち、新規→今買ってよい/押し目待ち/決算後まで待ち/ニュース確認/買わない。
- **出力**：各銘柄に「今日の結論」「ニュース要約」「株価影響」「シナリオ」「買う/待つ/売る」「Moomooで今日やること」。
- APIキー無しでもルールベースで動作（キーがあればニュース分類がAIに向上）。

### ニュース精密解析の使い方
1. 対象（保有/ウォッチ/発掘TOP20/今日のアクション）とニュース期間を選ぶ。
2. 各銘柄の「今日の結論」とシナリオ（強気/中立/弱気の確率とレンジ）を確認。
3. 「織り込み判定」で“もう動いた後か／まだ余地があるか”を把握。
4. マクロ連動で金利・原油・地政学などの効き方を確認。
5. 「Moomooで今日やること」に沿って手動で指値/逆指値を設定。

> ⚠️ シナリオの確率・株価レンジは過去の値動きとニュース傾向からの**目安**で、未来を断定しません。
> ニュースに日付が無い場合は便宜的に期間配分します。これは投資助言ではなく分析補助です。

- APIキー無しでもモックで発掘表示。Finnhub/OpenAIがあれば実ニュース＋AI分析を使用。

### 🔍 銘柄発掘ページの使い方（毎朝のルーティン）
1. 左メニュー「🔍 銘柄発掘」を開く（市場を自動スキャン）。
2. **TOP3カード**で今日の最有力3銘柄の「今日やること」を確認。
3. **TOP20テーブル**でスコア・判定・発掘理由・エントリー/損切り/利確・危険ポイントを確認。
4. 気になる銘柄を**「ウォッチリストに追加」**→ 以降は「個別銘柄分析」「売買プラン」で深掘り。
5. 「除外された銘柄と理由」も確認すると、なぜ買わない方がよいかが分かります。

### 発掘結果の注意点
- 発掘は**機械的なスクリーニング＋スコア**で、確実な上昇を保証しません。
- ユニバースは事前定義（`config.py` の `DISCOVERY_UNIVERSE`）。`user_data/universe.csv` に `ticker` 列で追記すると拡張できます。
- 重視テーマは `CURRENT_THEMES` で、相場が変われば手で調整してください。
- **必ず最新値をMoomooで確認し、損切りを決めてから判断**してください。

## 🧭 使い方

### A. 買う前（v2）
市場環境 → 今日のアクション → 個別銘柄分析 → 売買プラン → リスク管理 の順で確認。

### B. ポジション台帳の使い方（買った後）
1. 左メニュー「ポジション台帳」を開く。
2. 表に保有を入力（行追加で複数可）：**ティッカー / 平均取得単価 / 株数 / 購入日(YYYY-MM-DD) / メモ / 目的 / 初期損切り / 利確1 / 利確2**。
3. **💾 ポジションを保存**（`user_data/positions.json` に保存、次回自動読込）。
4. 下に各銘柄の評価カードが出ます：含み損益・保有日数・**今日やること**・**次のアクション（逆指値の引き上げ候補）**。
   - 新しいティッカーは保存→「🔄データ再取得」で分析が反映されます。

### C. Moomoo発注メモの使い方
1. 「発注メモ」ページで銘柄を選択。
2. **新規買いメモ**（第1〜3買い・損切り・利確1/2）をコピーしてMoomooの指値/逆指値設定の参考に。
3. 保有していれば**保有中メモ**（含み益・対応・逆指値引き上げ候補）も表示。

### D. アラートの見方
- 🔴危険：200日線割れ・損切り到達・強い悪材料など → すぐ確認。
- 🟠警告：50日線割れ・決算/FOMC接近・弱気ニュース → サイズ縮小を検討。
- 🔵情報：利確到達・高値更新・好材料 → 利確や監視の参考。

### E. 損切り・利確の考え方（初心者向け）
- **損切りは買う前に必ず決める**。到達したら機械的に実行（迷わない）。
- **利確は分割**：利確1で半分売って利益を確保 → 残りを伸ばす。
- **含み益が出たら損切りを切り上げる**（トレーリング）。取得単価以上に上げれば「最悪でも損しない」状態に。
- **イベント前は小さく**：決算前は保有の一部、FOMC前は全体のサイズを落とす。
